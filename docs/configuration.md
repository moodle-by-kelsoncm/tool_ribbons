# Configuração — moodle-tool_ribbons

1. Acesse:  
   **Administração do site → Plug-ins → Ferramentas de administração → Environment Ribbons**.
2. Defina a posição da faixa (ex: Superior Direito).
3. Insira a mensagem estática (ex: `DEV - AMBIENTE DE TESTES`) ou informe a URL de um script dinâmico.
4. Escolha as cores de fundo e texto da faixa.
5. Salve as alterações.
