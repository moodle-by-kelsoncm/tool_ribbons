Visão Geral - moodle-tool_ribbons (Environment Ribbons)
=======================================================

O **moodle-tool_ribbons** é um plugin de ferramenta de administração para Moodle que permite fixar **faixas de indicação visual (ribbons)** nos quatro cantos do site para identificar o ambiente (Desenvolvimento, Homologação, Produção, etc.) ou exibir textos dinâmicos (branch Git, link de pipeline, etc.).

Principais Recursos
-------------------

- **4 Cantos de Exibição**: Posicionamento nos cantos superior esquerdo, superior direito, inferior esquerdo ou inferior direito.
- **Conteúdo Estático ou Dinâmico**: Exibição de textos fixos ou dados carregados via script cURL em tempo real.
- **Suporte Moodle 3.10+ & Moodle 4.x/5.x**: Compatível com múltiplos temas e versões modernas.
