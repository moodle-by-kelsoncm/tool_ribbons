Installation
============

Installation Procedure
----------------------

1. Clone the repository into Moodle's administrative tools directory:

   .. code-block:: bash

      cd /path/to/moodle/admin/tool
      git clone https://github.com/moodle-by-kelsoncm/tool_ribbons.git ribbons

2. Access **Site administration > Notifications** to register the plugin and execute the database upgrade.
