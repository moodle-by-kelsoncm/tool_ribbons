Overview - moodle-tool_ribbons (Environment Ribbons)
====================================================

**moodle-tool_ribbons** is an administrative tool plugin for Moodle that allows displaying **visual indicator banners (ribbons)** in any of the four screen corners to identify the environment (Development, Staging, Production, etc.) or show dynamic runtime information (Git branch, CI/CD pipeline link, etc.).

Key Features
------------

- **4 Display Corners**: Position banners in top-left, top-right, bottom-left, or bottom-right corners.
- **Static or Dynamic Content**: Show fixed text or fetch real-time data via cURL script.
- **Moodle 3.10+ & Moodle 4.x/5.x Support**: Compatible with multiple themes and modern Moodle versions.
