Configuration
=============

Configuring the Ribbons
-----------------------

1. Go to:
   **Site administration > Plugins > Admin tools > Environment Ribbons**.
2. Set the ribbon position (e.g. Top Right).
3. Enter the static message (e.g. ``DEV - TEST ENVIRONMENT``) or provide the URL of a dynamic script.
4. Select the ribbon background and text colors.
5. Save changes.
