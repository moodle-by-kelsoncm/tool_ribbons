Guia de Uso & Scripts Dinâmicos
===============================

Uso com Scripts Dinâmicos
-------------------------

O plugin pode consumir URLs via cURL que retornam textos curtos, tais como:

- Nome da branch ativa do Git.
- Status do último pipeline de CI/CD.
- Identificador da versão de release.

Exemplos de scripts dinâmicos de amostra estão disponíveis na pasta ``/scripts/`` do repositório.
