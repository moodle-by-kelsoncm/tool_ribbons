Instalação
==========

Procedimento de Instalação
--------------------------

1. Clone o repositório no diretório de ferramentas do Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/admin/tool
      git clone https://github.com/moodle-by-kelsoncm/tool_ribbons.git ribbons

2. Acesse **Administração do site > Notificações** para registrar o plugin e executar o upgrade do banco de dados.
