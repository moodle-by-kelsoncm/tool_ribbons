# Instalação — moodle-tool_ribbons

## Procedimento de Instalação

1. Clone o repositório no diretório de ferramentas do Moodle:
   ```bash
   cd /caminho/do/moodle/admin/tool
   git clone https://github.com/moodle-by-kelsoncm/moodle-tool_ribbons.git ribbons
   ```
2. Acesse **Administração do site → Notificações** para registrar o plugin.
